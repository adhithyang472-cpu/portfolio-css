Project

Smart Energy-Efficient Ceiling Fan Using Temperature and Humidity Sensor

Category: IoT & Embedded Systems

Designed and developed an automated ceiling fan control system using a DHT22 temperature and humidity sensor and an ESP32 microcontroller. The system monitors room conditions in real time and automatically adjusts fan speed to maintain comfort while reducing unnecessary energy consumption.

Key highlights:

  • Real-time temperature and humidity monitoring via DHT22 sensor
  • Automatic fan speed adjustment using PWM control
  • Sensor interfacing and hardware integration on ESP32
  • Energy-efficient operation through intelligent automation

Technologies used: ESP32, DHT22, C / Arduino IDE, Sensor Interfacing, PWM Control
